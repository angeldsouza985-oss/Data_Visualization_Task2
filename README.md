# Data Visualization and Storytelling

## Objective
Created an interactive Power BI dashboard using the Superstore dataset to derive business insights and present them through visual storytelling.

## Tools Used
- Power BI
- GitHub

## Dashboard Components
- KPI Cards (Sales, Profit, Orders)
- Sales by Category
- Profit by Category
- Regional Sales Distribution
- Monthly Sales Trend
- Top 10 Customers by Sales
- Interactive Filters (Region, Category, Segment)

## Key Insights
- Technology category generated the highest sales and profit.
- West region contributed the largest share of revenue.
- A small group of customers generated significant sales.
- Sales showed seasonal variations throughout the year.
- Interactive filters allow deeper analysis.
